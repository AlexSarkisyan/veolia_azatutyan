# veolia-watch

Следит за каналом [@VeoliaJur](https://t.me/VeoliaJur) и присылает в личный
чат с ботом только те объявления об отключении воды, где встречается
ключевое слово. По умолчанию — `Ազատության` (проспект Азатутяна).

Работает на GitHub Actions, своя машина не нужна.

## Развёртывание

### 1. Репозиторий

Создать новый репозиторий и залить в него содержимое этой папки:

```
.github/workflows/veolia.yml
veolia_watch.py
requirements.txt
README.md
```

**Публичный или приватный.** В публичном минуты Actions не тарифицируются
вообще. В приватном на бесплатном тарифе даётся 2000 минут в месяц, а опрос
раз в 15 минут съедает около 2900 — не влезет. Поэтому для приватного
репозитория интервал в `veolia.yml` надо поменять на `*/30`.

Токен в код не попадает, он живёт в Secrets, поэтому публичный репозиторий
ничем не опасен.

### 2. Secrets

Settings → Secrets and variables → Actions → New repository secret.

| Имя | Значение |
|---|---|
| `VEOLIA_BOT_TOKEN` | токен от @BotFather |
| `VEOLIA_CHAT_ID` | числовой id личного чата |

### 3. Первый запуск

Вкладка Actions → veolia-watch → Run workflow.

Первый проход намеренно ничего не отправляет: он только запоминает текущую
позицию в канале и коммитит её в `veolia_state.json`. Иначе прилетела бы
пачка из двадцати старых постов. Со второго запуска приходит только новое.

## Что происходит при сбоях

`ParserBroken` — страница канала открылась, но постов в ней не нашлось.
Значит Telegram поменял вёрстку и селекторы перестали совпадать. Запуск
падает намеренно, чтобы GitHub прислал письмо. Без этого поломка была бы
незаметной: workflow зелёный, уведомления просто перестали приходить.

Сетевая ошибка при обращении к каналу не роняет запуск — позиция не
сдвигается, следующий проход через 15 минут подберёт пропущенное.

Если между запусками канал выдал больше постов, чем помещается на одной
странице, недостающие добираются через `?after=`.

## Известные ограничения

**Расписание.** Cron у GitHub не гарантированный: в часы пик запуск
откладывается, реальный интервал доходит до 20 минут. Для объявлений,
которые публикуют за несколько часов до отключения, это приемлемо.

**Спячка.** Запланированные workflow отключаются после 60 дней без
активности в репозитории. GitHub предупреждает письмом. Если уведомления
пропали — заглянуть на вкладку Actions и включить обратно.

**Площадь Свободы.** Ключ `Ազատության` встречается и в
`Ազատության հրապարակ` — это площадь в районе Кентрон, к проспекту
отношения не имеет. Такое объявление придёт как ложное срабатывание.
Отсев не делали намеренно: сначала надо увидеть реальную формулировку.

## Локальная проверка

```
python veolia_watch.py --selftest    # парсер и логика, без сети
python veolia_watch.py --dry-run     # сходить в канал, показать, не отправлять
python veolia_watch.py --loop 600    # цикл на своей машине
```

## Настройка ключей

Через переменную окружения, ключи через запятую:

```
VEOLIA_KEYWORDS=Ազատության,Քանաքեռ
```

В workflow добавляется в блок `env` того же шага.
